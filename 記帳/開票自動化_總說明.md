## 七、從 Gmail 信件解出附件(RAW 解碼)

get_message 用 **RAW**(過長自動存 tool-results),再解 MIME:

```bash
node -e '
const fs=require("fs");
const j=JSON.parse(fs.readFileSync(process.argv[1],"utf8"));
const mime=Buffer.from(j.raw.replace(/-/g,"+").replace(/_/g,"/"),"base64").toString("binary");
for(const p of mime.split(/--[0-9a-zA-Z=_.()+-]+\r?\n/)){
  let ext=null;
  if(/Content-Type:\s*image\/jpeg/i.test(p)) ext="jpg";
  else if(/Content-Type:\s*application\/pdf/i.test(p)) ext="pdf";
  else if(/Content-Type:\s*image\/png/i.test(p)) ext="png";
  if(ext){const b64=p.split(/\r?\n\r?\n/)[1];
    if(b64) fs.writeFileSync(process.argv[2]+"."+ext,Buffer.from(b64.replace(/\s/g,""),"base64"));}
}' <RAW結果檔> <輸出路徑不含副檔名>
```

jpg 縮圖後再 Read(省token):`python3 -c "from PIL import Image; im=Image.open('x.jpg'); im.thumbnail((900,900)); im.convert('RGB').save('x_s.jpg',quality=70)"`
PDF 加密先試密碼=統編;winmail.dat 為 TNEF 另解;掃描 PDF 轉圖後 Read。
