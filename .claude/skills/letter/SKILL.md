# 輕車函文製作(全文標楷體)

> 115/11/18 老闆定:**之後所有函文文字一律標楷體**(Word 與預覽 PDF 都要是楷書)。

## 一、開工

1. 先跑 `bash tools/setup_kaiti.sh`:雲端容器沒有微軟標楷體,此腳本安裝 AR PL UKai 並把「標楷體」對應過去,預覽 PDF 才會是楷書(每個新容器跑一次;輸出應為 `標楷體 → ukai.ttc: "AR PL UKai TW"`)。
2. 讀 `CLAUDE.md` 鐵律、`縣府案件/範本/輕車函文格式規範.md`、`縣府案件/範本/函文交件前檢核表.md`。
3. 來文先抓雲端「發文輕車-副本自存」資料夾(Drive parentId `1SEXplT7iT3e5xjTeFwxSL8kZUjELjx_r`)最新檔,讀全文,登記簿補收文。

## 二、製作流程

1. 寫 `縣府案件/NN_主題_函稿spec.json`(編號接續現有最大號;**先 `ls 縣府案件 | sort` 確認沒被別的對話用掉**)。
   - `date_roc: [115, 月, 日]` = 實際送件日;`seq` = 當日序號(同一天多封依序 1、2、3,**先查登記簿當天已用字號,避免重號**)。
   - 字號自動產生 `115北輕字第YYYMMDD-seq號`。
2. `python3 tools/qc_letter.py <spec.json> <輸出.docx>`:已內建全文標楷體(Normal 樣式與每個 run 的 ascii/hAnsi/eastAsia/cs 都設標楷體)、正本框、署名、頁碼。
3. 有附件:照 `縣府案件/30_附件插入Word.py` 的寫法另寫 `NN_附件插入Word.py`,圖片存 `縣府案件/附件/NN_主題/`;附件標題同樣用標楷體(`r.font.name='標楷體'` + `w:eastAsia`)。
4. `soffice --headless --convert-to pdf` 出 `_預覽.pdf`,`pdffonts` 確認是 `UKaiTW`,目視第 1 頁與最後一頁(日期、字號、署名、附件)。
5. SendUserFile 傳 Word + PDF。

## 三、內容規則

- 只寫可查證事實+出處;不寫評價、動機、指控犯罪;不副知廉政署、監察院。
- 引條號以 repo 已核對者為限(`縣府案件/00_總說明_必讀.md` 第二節);未核對寫「請釋明契約依據」。
- 待老闆定的地方用【　】標出並在回報中列出;**有【】不得用印**。
- 老闆改過的 Word:先 diff 出差異,沒有衝突照老闆版,有語病或事實風險就順稿並說明改了哪裡。

## 四、收尾

1. 登記簿 `縣府案件/收發文登記簿.csv` 新增或更新(發文字號、狀態寫實:草稿/待用印/已送)。
2. 有期限的排 Google 日曆提醒。
3. commit → push → 開 PR → 直接合併(文字類 PR 不訂閱追蹤)。
4. 送出後請老闆傳收文回執,登記簿改「已送」。
