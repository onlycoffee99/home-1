# 資歷庫說明

鑫和洋行及核心成員(鄭玉屏、張哲源、徐鈺清)之實績與學經歷總庫,供所有標案、企劃書、服務建議書引用。工作流程見 `.claude/skills/credentials/SKILL.md`。

## 檔案
| 檔案 | 內容 |
|---|---|
| `實績總表.csv` | 所有事項一行一筆(公司與個人共用),依編號遞增 |
| `公司_鑫和洋行.md` | 公司基本資料、品牌、標案用公司簡介(長/短版)、實績索引 |
| `人員_鄭玉屏.md` / `人員_張哲源.md` / `人員_徐鈺清.md` | 學經歷、專長、實績索引、標案用個人簡介 |
| `協力夥伴.md` | 協力人員(以個人名義參與)資料及同意書狀態 |

佐證照片壓縮版(長邊 1000px)存 `佐證/`;含個資的文件(同意書、證件)只存 Google 雲端硬碟「資歷庫佐證」資料夾(ID `1K0in_MmY2b16QGoYdkQGXGWaoliIsrpa`),不進 repo。

## 實績總表欄位
| 欄位 | 說明 |
|---|---|
| 編號 | R0001 起遞增 |
| 起日 / 迄日 | YYYY-MM-DD;只知年月寫 YYYY-MM;單日活動迄日同起日 |
| 歸屬 | 鑫和洋行 / 鄭玉屏 / 張哲源 / 徐鈺清,多人以「、」分隔 |
| 類別 | 場域經營、產品開發、品牌資產、產學合作、展會交流、文化活動、檢測認證、政府溝通、教育訓練、標案投標、學經歷 |
| 事項短版 | 一行,可直接放實績表 |
| 單位 | 委託/主辦/合作單位 |
| 角色 | 主辦、承辦、承租、進駐、參與、協辦、講師… |
| 評等 | A 有正式文件(合約、公文、證書、發票)/B 有照片或活動紀錄/C 僅口述 |
| 佐證 | 文件或照片名稱 |
| 雲端連結 | 雲端硬碟檔案連結(待上傳時留空) |
| 待補 | 缺什麼才能升級評等 |
| 引用紀錄 | 哪些標案用過、結果 |
| 登錄日 | 歸檔日期 |

## 評等用語對照(寫標案時)
- A:可寫「承辦」「受託」「簽約經營」「取得」
- B:寫「參與」「辦理」「參展」「交流」,不寫受託或得獎
- C:只寫「參與」,且投標前應先補佐證
