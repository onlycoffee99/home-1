## 上線步驟

1. 試算表已建好:雲端硬碟「森林風呂御神籤」資料夾內「森林風呂御神籤_回覆」(ID 已寫在 Code.gs)
2. 開 https://script.google.com → **新專案**(或從試算表 擴充功能 → Apps Script,兩種都可以)
3. 左邊已有 `程式碼.gs`:內容全刪,貼上 `Code.gs` 全部內容 → 存檔(💾)
4. 左邊「檔案」旁的 **＋ → HTML**,命名 `Index`(不要加 .html),內容全刪,貼上 `Index.html` 全部內容 → 存檔
5. 右上 **部署 → 新增部署作業**
   - 齒輪 → 選「**網頁應用程式**」
   - 執行身分:**我**
   - 誰可以存取:**所有人**
   - 按「部署」→ 第一次會要求授權:選你的帳號 →「進階」→「前往(不安全)」→ 允許
6. 複製「網頁應用程式網址」(`https://script.google.com/macros/s/.../exec`),貼給 Claude 做 QR code 立牌

> 之後若修改題目:改完存檔 → **部署 → 管理部署作業 → ✏️ → 版本選「新版本」→ 部署**,網址不變,QR code 不用重印。

## 櫃台怎麼發券

1. 客人出示籤詩畫面,確認:**時間在跳、綠點在閃**(是即時畫面,不是截圖),日期是今天
2. 在紙本咖啡券寫上畫面的**券號**,交給客人
3. 同一支手機當天再開,只會顯示同一張籤(畫面寫「今天已經抽過囉」),不能重複領
4. 月底對帳:試算表的券號數量 ≈ 發出的紙本券 ≈ 咖啡館收回的券

## 看統計

- 試算表「回覆」工作表:每欄一題,空白=這位客人沒抽到這題
- 統計滿意度時,每題分母用「該欄非空白、且不是『不清楚/沒注意』『今天沒開車』『今天沒需要幫忙』」的份數
