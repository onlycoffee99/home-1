# 短影音:迷糊老闆娘的日常(115/10/12 起)

老闆 115/10/12 語音交代的概念:每天一則「日常」,題材是時間到咖啡館的客人小故事、做飲料的過程、好笑的小插曲、人跟人見面的狀況,以及老闆自己的「迷路/迷糊」點滴。老闆沒辦法拍,所以改用**動畫插畫 + 字幕 + 配音**做成 30 秒直式影片(1080×1920,IG Reels/限動)。

## 做法(每集)
1. 老闆一句話講故事(語音即可)→ 我改寫成 5~6 句旁白(每句一個畫面)。
2. 改 `動畫.html`(畫面與時間軸都在 `render(t)` 裡)。
3. 出影格:`node tools/video_render.js 動畫.html frames 24 <秒數>`;配音 gTTS(zh-TW,1.22 倍速),音效用 ffmpeg 合成;`ffmpeg` 合成 mp4。
4. 給老闆看 → 老闆說 OK 才走行銷發布流程(IG Reels;LINE/Google 商家視情況)。

## 規則
- 只講老闆親口說過的事,不加油添醋成「事實」(例如不編造次數、日期、客人身分)。
- 客人故事一律匿名、不畫出可辨識的人。
- 結尾固定:時間到咖啡館|迷糊老闆娘的日常|EP.N|IG @5wudou。
