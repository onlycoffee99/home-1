## 每次 10 題怎麼抽

- 第 1 題固定:整體滿意度
- 中間 8 題打散:固定 3 題(溫泉水質、湯區清潔、你從哪裡來)+ 公園/風呂/店家 14 題抽 2 + 宜蘭好在地 8 題抽 1 + 旅遊行為 4 題抽 1(住幾晚、跟誰來、怎麼知道、還去哪)+ 趣味題 3 抽 1
- 第 10 題固定:年齡+來訪頻率;最後可留一句話(選填)
- 最後一頁可選填 email(須勾選同意,附個資說明);email 只存在試算表,`?export` 匯出時自動排除
- 答完先出現「第 X 番」籤支,點開看籤詩:24 支籤(115/10/26 由 13 支擴充):23 支吉籤機率相同(時間到大吉、大吉、身體吉、咖啡館吉、泡湯吉、森林吉、福吉、光明吉、花路吉、拼圖吉、自在吉、快樂吉、家和吉、良緣吉、學業吉、事業吉、旅人吉、好眠吉、財運吉、友情吉、平安吉、足湯吉、小確幸吉)+ 第二十四番「今日無抽中」(有籤詩祝福但不發券,試算表券號欄記「未抽中」;由後端決定,每人約 9%,每天最多 5 人,`Code.gs` 的 `NOWIN_PER_DAY`、`NOWIN_RATE`),每張含籤詩、解曰(中英)、願望/健康/旅行,以及「時間到咖啡館開運指南」(各籤不同的幸運飲品+開運行動)
- 題目、選項、籤名、解曰、領券提醒皆附英文小字(給外國遊客);存進試算表的仍是中文
- 籤詩下方紅色領券區:出示畫面到【森林風呂櫃台】索取咖啡券;憑紙本券到時間到咖啡館現折 30 元・限當日使用
- 文案一律「抽中再送/抽中就送」(不是每人都有券,避免廣告不實)
- **每日限量**:`Code.gs` 的 `DAILY_LIMIT`=100(台灣時間 0 點重算,0=不限);額滿後客人仍可填答抽籤,但不發券號,畫面顯示「今日咖啡券已送完」,試算表券號欄記「今日額滿」

## 上線步驟

1. 試算表已建好:雲端硬碟「森林風呂御神籤」資料夾內「森林風呂御神籤_回覆」(ID 已寫在 Code.gs)
2. 開 https://script.google.com → **新專案**(或從試算表 擴充功能 → Apps Script,兩種都可以)
3. 左邊已有 `程式碼.gs`:內容全刪,貼上 `Code.gs` 全部內容 → 存檔(💾)
4. 左邊「檔案」旁的 **＋ → HTML**,命名 `Index`(不要加 .html),內容全刪,貼上 `Index.html` 全部內容 → 存檔
5. 右上 **部署 → 新增部署作業**
   - 齒輪 → 選「**網頁應用程式**」
   - 執行身分:**我**
   - 誰可以存取:**所有人**
   - 按「部署」→ 第一次會要求授權:選你的帳號 →「進階」→「前往(不安全)」→ 允許
6. 複製「網頁應用程式網址」(`https://script.google.com/macros/s/.../exec`),貼給 Claude 做 QR code 立牌

> 之後若修改題目:改完存檔 → **部署 → 管理部署作業 → ✏️ → 版本選「新版本」→ 部署**,網址不變,QR code 不用重印。

## (舊)櫃台怎麼發券 — 115/10/26 起停用

1. 客人出示籤詩畫面,確認:**時間在跳、綠點在閃**(是即時畫面,不是截圖),日期是今天
2. 在紙本咖啡券寫上畫面的**券號**,交給客人
3. 同一支手機當天再開,只會顯示同一張籤(畫面寫「今天已經抽過囉」),不能重複領
4. 月底對帳:試算表的券號數量 ≈ 發出的紙本券 ≈ 咖啡館收回的券
